# 🐝 SCD30 Log Analyzer V2

SCD30 Log Analyzer V2 是一套用於**智慧蜂箱環境監測實驗**的網頁資料分析工具。

本系統可將 Jetson / SCD30 所記錄的多筆 CSV 資料直接匯入瀏覽器，自動整合並分析蜂箱內的：

- 🌡️ 溫度 Temperature
- 💧 相對濕度 Relative Humidity
- ☁️ 二氧化碳 CO₂

並提供每日、整體時間及自訂時間區間的資料分析與視覺化。

---

## ✨ 主要功能

### 📂 多筆 CSV 匯入
支援一次拖曳或選擇多個 SCD30 CSV 紀錄檔。

系統會自動：

- 合併多個 CSV
- 依照時間排序
- 辨識時間欄位
- 辨識溫度欄位
- 辨識濕度欄位
- 辨識 CO₂ 欄位

---

## 📊 資料分析

提供四種分析模式：

### 每日分析
選擇特定日期，查看當日：

- 平均值
- 最高值
- 最低值
- 最高值發生時間
- 最低值發生時間
- 趨勢圖

### 整體時間
分析所有匯入 CSV 的完整時間範圍。

### 自訂時間
自行設定開始與結束時間進行分析。

### 10:00–22:00 實驗時段
針對蜂箱 LED 光源實驗，自動分析：

`10:00:00 ≤ Time < 22:00:00`

---

## 💡 LED 光色實驗

目前支援：

| 光源 | 實驗日期 |
|---|---|
| 🟡 黃光 | 2026/07/15–2026/07/24 |
| 🔵 藍光 | 2026/07/25–2026/07/31 |
| 🟢 綠光 | 2026/08/01–2026/08/07 |
| 🔴 紅光 | 2026/08/08–2026/08/14 |
| ⚪ 暖白光 | 待設定 |

系統可依日期自動分類光色。

---

## 🌤️ 枋山外部氣象比較

可另外匯入枋山外部氣象 CSV，進行蜂箱內外環境比較。

主要指標：

- 箱內平均溫度
- 枋山平均溫度
- ΔT = 箱內平均溫度 − 枋山平均溫度
- 箱內平均濕度
- 枋山平均濕度
- ΔRH = 箱內平均濕度 − 枋山平均濕度

---

## 📈 趨勢圖

系統提供：

- 溫度趨勢
- 濕度趨勢
- CO₂ 趨勢
- 多日趨勢疊圖
- 箱內 vs 枋山比較

---

## ⚠️ 異常事件偵測

可設定變化門檻，自動尋找：

- CO₂ 突升
- 溫度快速變化
- 濕度快速變化

方便後續與可見光相機或 FLIR 熱像影像進行時間對照。

---

## 📥 Excel 匯出

分析完成後可直接匯出 `.xlsx`，包含：

1. 箱內合併原始資料
2. 每日 10:00–22:00 統計
3. 枋山原始資料
4. 異常事件
5. 目前選擇區間統計

---

## 🔒 資料隱私

CSV 資料主要於使用者瀏覽器端進行解析與分析。

本工具不需要將 SCD30 原始 CSV 上傳至 GitHub 儲存庫。
